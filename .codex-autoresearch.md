# Bounded Autoresearch: CoreNEURON/Hay Simulator Metrics

Date: 2026-06-05

## Target

Improve defensible model metrics for the NEURO-BENCH single-neuron surrogate
paper after replacing the Arbor path with a CoreNEURON-compatible Hay path.

## Hard Constraints

- Correctness and simulator defensibility dominate metric improvement.
- Do not use model training runs larger than `80k` presentations for the
  current metric-measurement phase.
- Use Mamba first for model measurements because it is faster.
- Do not count faster convergence tricks as a valid simulator improvement unless
  the change remains defensible for longer runs.
- Do not select validation seeds/splits merely because they improve RMSE.

## Baseline

- Simulator path: CoreNEURON-compatible Hay L5PC with deterministic synapse
  subsets matching the source-teacher deterministic release policy.
- Dataset baseline: `data/hay-coreneuron-source-sanity-4_4-20260605`.
- Model baseline: `mamba_compact80k` from
  `docs/verify-arbor-simulator/artifacts/nmda_mamba_compact_80k_20260604/mamba_compact_80k_best.pt`.
- Initial metric: M1 soma RMSE, with M1 AUC, M1b feature errors, M2 near-spike
  RMSE, spike count/timing, teacher spike rate, and teacher clipped-voltage
  stats as guards.

## Candidate Interventions

1. **Scientific/free lunch:** Turn the exact CoreNEURON probe into a dataset
   generator. Premise: same Hay dynamics, same target policy, GPU-capable
   simulator path, no biological concession.
2. **Scientific:** Validate fixed-step/CoreNEURON output on larger held-out
   samples before claiming metric improvement. Premise: small split results may
   be seed/easiness artifacts.
3. **Scientific:** If RMSE remains high, inspect error by M2 regime and M1b
   features before changing simulator settings. Premise: defensible changes
   should target a real dynamic mismatch, not arbitrary convergence speed.
4. **Blind but bounded:** If no simulator-fidelity issue is found, run only
   small <=80k Mamba training/evaluation comparisons with one attributable
   change at a time.
