# AxoMamba Model Autoresearch

## Target

Improve AxoMamba on the fixed AxoBench v1 dataset while preserving defensible
failure-mode behavior. Optimize primarily for voltage/dynamics SERA,
F1-over-time, and intervention response SERA.

## Experiment Contract

- Task arc: `docs/axomamba-autoresearch/`
- Runner: `scripts/run_axomamba_autoresearch.py`
- Default budget: exactly 120,000 training presentations.
- Long budget: exactly 300,000 presentations on every tenth iteration.
- Dataset: `data/v1-neuronio-like-gpu-20260611`.
- Frozen presentation schedule: shared by all candidates in a comparison.
- Diagnostics output: `docs/axomamba-autoresearch/artifacts/diagnostics/`.
- Baseline diagnostics: load a frozen output artifact; do not rerun baseline
  inference for each candidate.
- Results ledger: `.codex/experiments/results.tsv` and
  `docs/axomamba-autoresearch/autoresearch_progress.md`.
- Code cleanup: every tenth iteration, remove rejected/dead modifications
  after verifying they are not used by retained runs.

## Decision Policy

Each iteration records the candidate mechanism, whether the test is scientific
or blind, run configuration, exact presentation and optimizer-step counts,
diagnostic deltas, failure triggers, interpretation, and keep/discard decision.
Multiple independently attributable candidates may run in one iteration.
High-temperature structural/objective changes come before low-temperature
tuning. Do not launch ideas without a stated mechanism or direct objective.

## Read-only Inputs

- AxoBench v1 dataset and manifests.
- Frozen baseline checkpoint and baseline diagnostics artifact once selected.
- Historical run artifacts unless explicitly promoted into the current arc.
