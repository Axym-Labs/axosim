# AxoMamba Model Autoresearch

## Target

Improve AxoMamba on the fixed AxoBench v1 dataset while preserving defensible
failure-mode behavior. Optimize primarily for voltage/dynamics SERA,
F1-over-time, and intervention response SERA.

The corrected phase ran exactly 15 iterations, I557-I571. A cheap
adaptive surrogate advances every exact P4 boundary from all ordered native
inputs and emits four distinct native outputs. A causal uncertainty gate
accepts that block or invokes the mature P4 Mamba on the selected neurons'
accumulated exact history and uses its four native outputs for that block.
The surrogate continues advancing regardless; synchronizing its hidden state
after a Mamba block is optional and may be tested only if repeated corrections
become a measured cost problem. The primary metrics are canonical AxoBench
SERA, F1 area, complete-stack throughput, and the correction fraction needed
to stay inside the declared SERA/F1 envelopes. Every promoted surrogate must
execute the 1,278-value trainable per-neuron adaptation ABI and beat a
shared-only control on neuron-specific behavior preservation.

P16/P32 next-block forecasting is adjacent evidence only. Never replace the
P4 surrogate cadence with the correction horizon, average inputs or outputs,
require a correction to persist into future surrogate predictions, or evaluate
a model-only timing path as the connected headline.

## I557-I571 Result

The exact surrogate-only control closes at `4.89789 ms/P4` and `856.35M`
neuron-steps/s with `3.79137 Hz` population activity. Exact unique-row routing
is retained; split population GEMM GRU and dense all-row queue consumption are
rejected. Non-surrogate work leaves only `1.31 ms/P4` for a cheap adaptive
surrogate plus average Mamba corrections. The next premise must therefore
train a materially cheaper adaptive support surrogate before adding causal
current-block Mamba replacement. Hidden-state repair is not required.

## I572-I599 Result

The state-32 distilled support surrogate plus exact routing now clears the
million-neuron target without correction at `1.2771B` median and `1.2577B`
p90 neuron-steps/s. This is the regression and maximum-throughput profile.
The optional spike-quality profile applies causal internal-state correction
to an exact `1.75%` of blocks and reaches `1.1278B` median and `1.1117B` p90,
while held-out F1 area improves `0.37212 -> 0.39924`. Predicted-voltage
histograms and a direct causal SERA-benefit gate recover at most `0.0556 mV`
SERA across the tested fractions, below the `0.1 mV` materiality threshold;
regression correction is therefore rejected. Keep the two profiles distinct
and use `artifacts/million-neuron-deployment-frontier.md` as the evidence
index.

## Experiment Contract

- Task arc: `docs/axomamba-autoresearch/`
- Runner: `scripts/run_axomamba_autoresearch.py`
- Default budget: exactly 120,000 training presentations.
- Long budget: exactly 300,000 presentations on every tenth iteration.
- Dataset: `data/v1-neuronio-like-gpu-20260611`.
- Frozen presentation schedule: shared by all candidates in a comparison.
- Diagnostics output: `docs/axomamba-autoresearch/artifacts/diagnostics/`.
- Baseline diagnostics: load a frozen output artifact; do not rerun baseline
  inference for each candidate.
- Results ledger: `.codex/experiments/results.tsv` and
  `docs/axomamba-autoresearch/autoresearch_progress.md`.
- Code cleanup: every tenth iteration, remove rejected/dead modifications
  after verifying they are not used by retained runs.

## Decision Policy

Each iteration records the candidate mechanism, whether the test is scientific
or blind, run configuration, exact presentation and optimizer-step counts,
diagnostic deltas, failure triggers, interpretation, and keep/discard decision.
Multiple independently attributable candidates may run in one iteration.
High-temperature structural/objective changes come before low-temperature
tuning. Do not launch ideas without a stated mechanism or direct objective.

## Read-only Inputs

- AxoBench v1 dataset and manifests.
- Frozen baseline checkpoint and baseline diagnostics artifact once selected.
- Historical run artifacts unless explicitly promoted into the current arc.
