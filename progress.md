## 2026-05-05

- **Mamba-lite state of evidence before new change**: matched 40k-presentation probes show plain branch Mamba-lite at best val RMSE `1.4356 mV`, AUC `0.9570-0.9611`; integrative Mamba-lite with explicit long-timescale mixing at best RMSE `1.2045 mV`, AUC `0.9743`. This confirms the earlier qualitative finding that the plain parallel temporal mixer is too spike-like/impulsive, and that adding low-frequency temporal structure helps, but it is still far behind Branch-ELM at comparable or larger budgets.
- **Hypothesis: branch-level synaptic trace before Mamba temporal mixing**. Branch-ELM applies an exponential synaptic trace before branch integration. Because a shared linear exponential filter commutes with branch summation, a cheap branch-level trace should reduce raw spike impulses while preserving simplicity/scalability. Implemented optional `use_branch_trace` in `BranchMambaLite`, plus `configs/branch_mamba_lite_branchtrace_45x64.json` and preset `mamba-lite-branchtrace-probe`. The trace adds only `45` trainable gain parameters (`142,511` vs `142,466`) and keeps old Mamba checkpoints load-compatible.
- **Branch-trace probe result: negative vs integrative Mamba-lite**. Matched 2 epoch x 20,000 samples, batch 8, random full-trace, CUDA run: `/workspace/runs/mamba_lite_branchtrace_probe_2x20000_b8_cuda_20260505/metrics.json`. Best epoch `2`; best val RMSE `1.3013 mV`; AUC `0.9712`; total time `657.1s`; epoch train throughput `77.6-80.1 samples/s`. It improves over the original plain Mamba-lite (`1.44 mV`) but is worse than the existing integrative Mamba-lite (`1.2045 mV`) and slightly slower end-to-end.
- **Behavior diagnostic for branch trace**: first-8 full-trace val diagnostic at `/workspace/runs/mamba_lite_branchtrace_probe_2x20000_b8_cuda_20260505/behavior_diagnostic_first8.json`. Branch trace reduced soma step roughness relative to integrative Mamba-lite (`step_abs_ratio_to_target 1.13` vs `1.23`) but had worse raw normalized RMSE (`0.1402` vs `0.1256`) and lower soma correlation (`0.9699` vs `0.9744`). Learned branch trace gains moved below the `0.5` initialization on average (`mean 0.458`, range `0.335-0.556`), suggesting the imposed trace was not the missing mechanism; it smooths, but loses useful timing/amplitude information.
- **Hypothesis: gated feature-level leaky state inside Mamba block**. Instead of smoothing raw branch inputs, add a diagonal low-pass state bank after the block's gated short/long temporal features, so feature extraction can decide what should enter slow state. Implemented optional `use_state_trace` and `configs/branch_mamba_lite_statetrace_45x64.json`; preset `mamba-lite-statetrace-probe`. This adds `512` trainable state-mix logits (`142,978` params total) and keeps forward cost close to branch trace (`~2.16 ms` per batch-8 500-step forward vs `~1.80 ms` integrative).
- **State-trace probe result: small positive on RMSE, neutral/negative on AUC and cost**. Matched CUDA run: `/workspace/runs/mamba_lite_statetrace_probe_2x20000_b8_cuda_20260505/metrics.json`. Best epoch `2`; best val RMSE `1.1887 mV`; AUC `0.9727`; total time `603.7s`; epoch train throughput `75.7-79.3 samples/s`. This narrowly beats integrative Mamba-lite RMSE (`1.2045`) at the same 40k presentations, but AUC is slightly worse (`0.9727` vs `0.9743`) and still far from Branch-ELM.
- **Behavior diagnostic for state trace**: `/workspace/runs/mamba_lite_statetrace_probe_2x20000_b8_cuda_20260505/behavior_diagnostic_first8.json`. State trace improved first-8 raw normalized RMSE/correlation vs integrative (`0.1231`, corr `0.9753` vs `0.1256`, corr `0.9744`) but did **not** simply smooth the trace: step roughness was higher (`step_abs_ratio_to_target 1.30` vs `1.23`). Learned state mix stayed broad around the `0.5` initialization (`mean 0.502`, range `0.288-0.834`), suggesting useful feature-level state selection rather than uniform damping. Spike logits for positives were slightly more negative than integrative, consistent with the small AUC loss.
- **Decision on Mamba replacement direction**: branch-level fixed smoothing is not worth continuing as the main path. Feature-level leaky state remains alive but only as a weak lead; the next Mamba ablation should isolate whether the long convolution is now redundant (`state_trace` without `long_conv`, or shorter long kernel) and whether separate spike/voltage temporal paths can recover AUC without losing the RMSE gain. The Mamba replacement is not "done": current best Mamba-lite still trails Branch-ELM materially (`1.1887 mV` vs official-sampler probe `0.968 mV` at 80k and long random Branch-ELM `0.762 mV`), despite much better per-step throughput.
